linux 介绍

Linux 是一种开源的类 Unix 操作系统，广泛应用于服务器、个人电脑和嵌入式系统，因其稳定性和灵活性而受到欢迎。

Linux的特点：

  • 开源：Linux 的源代码是公开的，任何人都可以自由获取、修改和分发，这使得它拥有庞大的开发者社区，推动了其不断发展和创新。
  • 稳定性：Linux 被认为是一个性能稳定的操作系统，尤其适合用于服务器环境。
  • 多样性：Linux 有许多不同的发行版，如 Ubuntu、Red Hat、CentOS、Debian 等，每个发行版都有其特点和适用场景
  • 安全性：Linux 系统通常被认为比其他操作系统更安全，尤其是在服务器和网络环境中，因其权限管理和用户管理机制较为严格。

其中linux与windows最大的区别之一就是windows是开箱即用的能用纯ui使用的，但用linux你就不得不与命令行打交道，
但好消息是linux提供了比windows乐色一样的命令行强大的多的命令行工具帮住我们管理文件、目录、软件、配置和系统。

查询命令的使用方法

你不可能完整的记住所有命令的使用方法和参数，最好的方法就是知道如何去查询命令该如何使用，以下介绍两种查询方法

{command} --help:

大多数命令都会提供一个--help的flag项，如果你不清楚一个命令有什么用，那就大胆的--help你就能得到你需要的细节

例如对ls进行查询：

输出：

man {command}：查看完成的使用手册

man命令是manual的缩写，用来查看各种命令、函数和配置的完整手册，一般会比--help查到的信息更加完整

使用方法：man [选项] [节号] 命令

主题：

  • -f：显示与指定关键字相关的手册页面。
  • -k：搜索手册页中与关键字匹配的条目。
  • -a：显示所有匹配的手册页面。
  • -w：仅显示手册页的位置，而不显示其内容。

常见的节号包括：

  1. 用户命令
  2. 系统调用
  3. C库函数
  4. 设备和特殊文件
  5. 文件格式和约定
  6. 游戏和演示
  7. 杂项
  8. 系统管理命令

文件与目录相关命令

ls：列出目录命令

ls的语法是ls [选项] [目录/文件]

最核心的显示格式选项:

  • -l（长格式）是使用频率最高的选项，输出包含权限、链接数、所有者、组、大小、修改时间和文件名。

  • -h（人类可读）必须配合-l或-s使用，把字节数转成1K、234M这类易读单位。

  • -a/-A控制隐藏文件：-a显示所有包括.和..；-A显示隐藏文件但不显示这两个特殊目录。

  • -F/--classify在文件名后追加类型指示符：目录加/，可执行文件加*，符号链接加@，管道加|。

排序与时间相关:

  • -t按修改时间排序，最新的在前。-S按文件大小排序，大的在前。-r反转排序顺序。-X按扩展名排序。

  • -c配合-lt时按状态变更时间排序并显示;-u配合-lt时按访问时间排序并显示。

递归与目录处理:

  • -R递归列出所有子目录内容,不推荐使用，更推荐使用tree命令，能更直观的展示目录层级。

信息增强选项:

  • -i显示inode号（linux文件或目录唯一的标识码）。
  • -g让目录排在文件前面。
  • -L对符号链接显示其指向目标的信息，而非链接本身。

常用组合速查:

组合 效果
ls -lh 详细列表+易读大小（最常用）
ls -lht 详细列表+易读大小+按时间排序
ls -la 详细列表+包含隐藏文件
ls -lha 上述两者的结合

pwd: 当前目录命令

这是一个相当简单的命令，就两种使用方法

  • pwd/pwd -L(Logical)：显示环境变量的逻辑目录
  • pwd -P(Physical)：解析符号链接，显示真实的底层的物理目录

cd: 切换目录命令

cd的语法：cd [目录]

参数也和pwd一样只有-L/-P,且用法一致，-P会额外将pwd当前目录重置为真实的物理目录

常见的特殊参数：

  • 不带参数/cd ~：直接回到当前用户的home目录
  • ..：回到上一级目录
  • -： 回到上一个工作目录，在两个工作目录间切换成很常用
  • ~{username}： 回到某个用户的home目录
